# simple-cli

A minimal Codex-like CLI backed by DeepSeek.

## Setup

Install dependencies:

```bash
npm install
```

Create a local config from the example file:

```bash
copy config.local.example.json config.local.json
```

Then fill in your local `apiKey` in `config.local.json`.

## Run

```bash
npm start
```

After a global install, launch the interactive shell with:

```bash
scli
```

## Test

```bash
npm test
```
