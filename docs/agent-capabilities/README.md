# Agent 能力文档体系

这个目录用于记录 `simple-cli` 的 agent 能力建设过程。后续每实现一个关键能力，都需要同步补一份能力文档，避免只留下代码而没有设计背景。

每份能力文档必须回答四个问题：

- 为什么要做这个能力？
- 它解决了什么具体问题？
- 我们是怎么实现的？
- 如何验证它真的有效？

## 文档原则

- 先写清楚问题，再写方案。
- 每个能力只解决一个主要问题，不把多个方向混在一份文档里。
- 记录取舍，尤其是没有做的部分。
- 记录验证方式，包括自动化测试、手工验证、失败案例。
- 每次迭代后补充“后续改进”，方便回顾。

## 固定结构

新能力文档统一从 [TEMPLATE.md](./TEMPLATE.md) 复制，然后按实际内容填写。

推荐命名：

```text
NNN-capability-name.md
```

示例：

```text
001-tool-protocol-layer.md
002-tool-permission-system.md
003-context-management.md
```
